# 囚徒困境：群体版（博弈论学习项目）

一个仿照 [ncase/trust](https://ncase.me/trust/) 风格的网页交互实验，目前先完成**囚徒困境**核心玩法。

## 课程内容

- **第一课 · 群体囚徒困境**：玩家与多位 AI 决策者同时选择合作或不合作，可调整决策者总数和每位 AI 的合作倾向。
- **第二课 · 多智能体学习**：多位智能体拥有不同的初始信任和学习率，每轮根据玩家的选择更新信任，从而改变未来的合作概率。
- **第三课 · 收益驱动学习**：玩家不参与决策；智能体观察上一轮其他智能体的选择，理性比较合作与不合作的收益后决定继续或改变决策。玩家可设定智能体数量、理性程度、收益规则与模拟轮数，并切换“囚徒困境”与“临界合作”两种博弈，观察唯一均衡与双均衡的区别。
- **现实情景模式**：将囚徒困境包装为 996 加班、寝室打扫、小组作业等真实生活故事关卡，玩家在剧情中做选择，完成后获得博弈论启示。

## 当前规则

- 玩家是 **决策者 1**。
- 每轮玩家与多位 AI 决策者（a1、a2……）同时做出选择。
- 决策者总数（含玩家）可在 2～12 人之间自由增减。
- 每位 AI 决策者都可以拖动滑块调整**合作倾向**（概率），因此不会固定选择。
- 可选决策：
  - **A · 合作**：自己收益 `-1`，其他每一位决策者收益 `+3`。
  - **B · 不合作**：自己和其他决策者收益变化均为 `0`。
- 玩家收益 = 自己决策带来的收益 + 其他选择合作者人数 × 3。
- 可连续进行多轮，查看收益累计和历史记录。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

也可以在目录中启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件结构

- `index.html`：页面结构
- `styles.css`：界面样式
- `game.js`：第一课游戏逻辑
- `lesson2.js`：第二课多智能体学习逻辑
- `lesson3.js`：第三课收益驱动学习与自动模拟逻辑
- `scenario.js`：现实情景模式的故事关卡与博弈论启示
- `app.js`：课程切换
