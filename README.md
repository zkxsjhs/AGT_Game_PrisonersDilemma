# 囚徒困境：群体版（博弈论学习项目）

一个仿照 [ncase/trust](https://ncase.me/trust/) 风格的网页交互实验，目前先完成**囚徒困境**核心玩法。

## 当前规则

- 玩家是 **决策者 1**。
- 每轮玩家与 5 位 AI 决策者（a1～a5）同时做出选择。
- 每位 AI 决策者有不同的**合作倾向**（概率），因此不会固定选择。
- 可选决策：
  - **A · 合作**：自己收益 `-1`，其他每一位决策者收益 `+3`。
  - **B · 不合作**：自己和其他决策者收益变化均为 `0`。
- 玩家收益 = 自己决策带来的收益 + 其他选择合作者人数 × 3。
- 可连续进行多轮，查看收益累计和历史记录。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

也可以在目录中启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件结构

- `index.html`：页面结构
- `styles.css`：界面样式
- `game.js`：游戏逻辑
